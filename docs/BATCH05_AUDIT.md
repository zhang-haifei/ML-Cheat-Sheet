## 科学修订

- 分类/回归按目标区分，监督/无监督按信号区分；无监督不是天然较差。
- 真实标签、预测类别、实值得分和概率分别说明。决策边界允许真实标签落在“错误”一侧。
- 原容量图曾被放在“泛化能力”标题下。现分别定义表达集合与新数据表现；参数数量并非通用度量。
- 固定输入维度和网络结构时，神经网络也属于有限参数模型；非参数不等于无参数。
- Type II原图文字写“假阳性”，与自己的例子矛盾。纠正为在相应H0/正类约定下的假阴性，说明未拒绝不等于证明H0。
- 偏差与预测方差明确固定x、重复训练集、条件均值；噪声不直接称作残差。
- 平方损失分解声明新噪声独立与零条件均值；避免把变量相关一概当噪声来源。
- 复杂度与偏差方差之间不写成普遍单调规律；验证误差不保证单一U形。
- Occam与NFL各有条件；删除“任一算法总存在随机猜测严格更好目标”的过强解释。
